# Muhammad Asif — Personal Portfolio

A responsive personal portfolio website for **Muhammad Asif**, a PHP & Laravel Full Stack Developer.

The portfolio is designed to present professional information, technical skills, projects, experience, and contact details in a clean and responsive interface.

---

## 📌 Project Overview

This portfolio website was developed as part of the **DecodeLab Internship** project.

The main goal of the project is to create a professional, responsive, accessible, and interactive developer portfolio using modern frontend development practices.

The website focuses on:

- Professional presentation
- Responsive design
- Semantic HTML
- CSS Flexbox and Grid
- Responsive typography
- JavaScript interactions
- Accessibility
- Clean and maintainable code
- Consistent design system

---

## 🎯 Objectives

The main objectives of this project are:

- Create a professional personal portfolio
- Present developer skills and experience
- Showcase completed projects
- Provide downloadable resume access
- Provide professional social links
- Add a functional-looking contact interface
- Implement responsive layouts for different screen sizes
- Follow semantic HTML practices
- Use CSS Grid and Flexbox appropriately
- Implement responsive typography using `clamp()`
- Add JavaScript-based interactions
- Maintain a consistent visual design system

---

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### HTML

Semantic HTML elements are used throughout the website to improve structure, accessibility, and maintainability.

Examples include:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`
- `<form>`
- `<label>`
- `<button>`

### CSS

The project uses modern CSS techniques including:

- CSS Variables
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries
- `clamp()`
- Transitions
- Hover Effects
- Responsive Spacing
- Responsive Typography

### JavaScript

JavaScript is used to provide interactive functionality such as:

- Mobile navigation
- Navigation state handling
- Scroll-based interactions
- Interactive UI behavior
- Other portfolio interactions
